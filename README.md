
# ShopEase - Interactive Shopping App Prototype

## Project Overview
ShopEase is an interactive e-commerce shopping application prototype developed for VINIX Internship Task 8.

The project demonstrates product browsing, shopping cart management, search, filtering and a demo checkout process.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Key Features
- Responsive user interface
- Product listing
- Product search functionality
- Category filtering
- Product details popup
- Add to cart functionality
- Increase and decrease product quantity
- Remove products from cart
- Automatic total price calculation
- Checkout form validation
- Demo order confirmation

## Folder Structure
- index.html
- style.css
- script.js
- README.md
- assets/images/

## How to Run
1. Clone the repository.
2. Open the project in VS Code.
3. Open index.html using Live Server.
4. Explore products and test shopping features.
